# Datasets

Generated by `ml/preprocessing/build_dataset.py`. Raw and processed files are
git-ignored; this file documents sources and licensing.

| Source | URL | Label | License |
|---|---|---|---|
| SpamAssassin public corpus (2003-02-28, 2005-03-11) | https://spamassassin.apache.org/old/publiccorpus/ | LEGITIMATE / SPAM | Public research corpus; message copyright remains with senders |
| Jose Nazario phishing corpus (2023–2025) | https://monkey.org/~jose/phishing/ | PHISHING | CC-BY-4.0 — attribution: Jose Nazario |

Actual counts and split statistics are recorded in
[`docs/model_report.md`](../../docs/model_report.md) and `metadata.json` of each
artifact. The corpora are historical research data; never deliver their messages
to live mail systems.

```bash
backend/.venv/bin/python ml/preprocessing/build_dataset.py
backend/.venv/bin/python ml/training/train.py --version 1.0.0
backend/.venv/bin/python ml/evaluation/evaluate.py --version 1.0.0 --update
```
